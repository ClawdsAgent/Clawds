# Research brief

1. Restate the question in one line and note what a good answer must decide.
2. Gather from several independent sources; prefer primary ones (docs, source code, official posts). Note the date of each source.
3. Separate **facts** (with source) from **opinions** and from **your inference**. Never present a guess as a fact.
4. Write the brief: a 2-3 sentence answer first, then key points, then a comparison table if there are options, then open questions.
5. List sources as links at the end. Save the full notes in `notes/<topic>.md` in the workspace and post only the summary to the chat.
6. If sources disagree or are weak, say so and give a confidence level.
