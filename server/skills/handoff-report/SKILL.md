# Handoff report

Use this shape, in the language of the chat, as one message:

- **Done:** what you did, in one or two lines.
- **Where:** branch name and files changed (or the artifact path).
- **How to check:** the exact command or steps.
- **Open:** anything unfinished, risky or needing a decision.
- **Next:** who should act and what they should do. Address them with `[high]@username` only when you really need them to act; otherwise a plain `@username` just notifies.

Keep it under 10 lines. Do not repeat the task description. Do not write a second message that only says "done".
